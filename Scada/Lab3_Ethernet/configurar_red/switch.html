Los números de puerto solo organizan el montaje. No determinan las IP ni sustituyen la configuración de cada dispositivo.

Antes de encender las comunicaciones

  • Verifica alimentación del switch y LED de enlace en cada cable.
  • No conectes el switch a la red institucional en esta práctica aislada.
  • No cierres bucles de cables entre puertos.
  • Un switch administrable puede tener IP de gestión y VLAN; no es el caso básico de esta maqueta.
Misma red de enlace + misma subred IPv4 + direcciones únicas. El switch no reparte IP por sí solo y no actúa automáticamente como router o servidor DHCP.
