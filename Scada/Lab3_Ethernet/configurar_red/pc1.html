Configura el equipo paso a paso

Ubica el adaptador del laboratorio

Conecta este PC al switch. Anota su configuración actual para restaurarla al terminar. Trabaja sobre Ethernet, no sobre Wi-Fi, VPN ni adaptadores virtuales.

Abre la ruta del Panel de control

Inicio → Panel de control → Redes e Internet → Centro de redes y recursos compartidos → Cambiar configuración del adaptador

También puedes abrir Win + R, escribir ncpa.cpl y pulsar Enter para llegar a Conexiones de red.

Entra a las propiedades de IPv4

Clic derecho en Ethernet → Propiedades. Selecciona Protocolo de Internet versión 4 (TCP/IPv4) y pulsa Propiedades.

Escribe la dirección de este PC

Marca Usar la siguiente dirección IP. Para esta LAN aislada, completa:

Propiedades de IPv4 · PC1
Dirección IP192.168.10.20
Máscara de subred255.255.255.0
Puerta de enlaceDejar vacía
DNS preferido / alternativoDejar vacíos
Esquema didáctico de campos · no es una captura del programa.

No inventes un gateway .1: en esta maqueta no hay router. La configuración de DNS no impide acceder por IP a un equipo local; OPC DA puede requerir además resolver el nombre del PC remoto.

Aplica y verifica

Confirma con Aceptar y cierra las propiedades. Abre una terminal y comprueba el adaptador correcto:

ipconfig /all
ping 192.168.10.10

La IP mostrada debe coincidir con la elegida. Si ping no responde, revisa enlace y configuración; no concluyas todavía que el PLC está averiado.

Ahora configura el enlace de KEPServerEX

En PC1, el destino del driver es el PLC 192.168.10.10, no la IP del propio PC.

AjusteValor de referencia

TagsDirecciones, tipos y escalado del mapa entregado por el docente.

Valida un tag en OPC Quick Client antes de abrir Infilink en PC2. No se requiere instalar un segundo KEPServerEX en PC2 para una conexión DA remota directa, aunque sí los componentes cliente OPC/DCOM necesarios.

Si el PLC conserva su dirección inicial 192.168.1.5, pasa primero a la página DCISoft: durante esa etapa PC1 puede necesitar la IP temporal 192.168.1.20. Después vuelve a 192.168.10.20.
