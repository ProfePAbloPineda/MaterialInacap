Ubica el adaptador del laboratorio

Conecta este PC al switch. Anota su configuración actual para restaurarla al terminar. Trabaja sobre Ethernet, no sobre Wi-Fi, VPN ni adaptadores virtuales.

Abre la ruta del Panel de control

Inicio → Panel de control → Redes e Internet → Centro de redes y recursos compartidos → Cambiar configuración del adaptador

También puedes abrir Win + R, escribir ncpa.cpl y pulsar Enter para llegar a Conexiones de red.

Entra a las propiedades de IPv4

Clic derecho en Ethernet → Propiedades. Selecciona Protocolo de Internet versión 4 (TCP/IPv4) y pulsa Propiedades.

Aplica y verifica

Confirma con Aceptar y cierra las propiedades. Abre una terminal y comprueba el adaptador correcto:

ipconfig /all
ping 192.168.10.10

La IP mostrada debe coincidir con la elegida. Si ping no responde, revisa enlace y configuración; no concluyas todavía que el PLC está averiado.

Conecta Infilink con PC1

Para la interfaz OPC DA con campos Prog ID y Remote machine:

  1. En diseño, crea un OPC Tag Group, por ejemplo OPC_PC1.
  2. En Prog ID usa el identificador real del servidor, por ejemplo Kepware.KEPServerEX.V6 si corresponde a la instalación.
  3. En Remote machine escribe el nombre real de PC1, obtenido allí con hostname. Confirma que se resuelva a 192.168.10.20.
  4. Define Update Rate, por ejemplo 1000 ms. Añade un tag con Server item Canal.Dispositivo.Tag, usando la ruta real.
El docente debe preparar permisos, identidades, componentes OPC y reglas Windows/DCOM. Abrir 4840 no habilita OPC DA. Si el software usa OPC UA, se configura un endpoint y seguridad UA; no se coloca una URL UA en Prog ID.

Asocia un indicador al tag, ejecuta Infilink y varía la señal. Compara su valor con el cliente de prueba de PC1.
