DCISoft

Configura el equipo paso a paso

Identifica el PLC correcto

Conecta el puerto Ethernet del Delta DVP-SE al switch. Identifica el equipo por modelo y MAC. El módulo 06XA unido a su costado no necesita dirección IP.

Prepara la conexión inicial

Si el PLC ya tiene una IP conocida, utiliza ese segmento para configurarlo. En un DVP-SE con ajustes iniciales, el manual indica 192.168.1.5 con máscara 255.255.255.0; verifica que no haya sido modificado.

Si conserva ese ajuste, asigna temporalmente a PC1 192.168.1.20 / 255.255.255.0, sin gateway. Esa IP temporal no es la dirección final de PC1.

Selecciona Ethernet en DCISoft

DCISoft → Tools → Communication Setting → Ethernet

Selecciona la interfaz Ethernet del laboratorio si aparece un selector de adaptador. Confirma y utiliza Auto Search / Search para localizar el PLC.

Abre su configuración de red

Doble clic en el equipo encontrado; identifica su MAC antes de editar. Abre la pestaña Basic y el área Network Setup. Elige IP estática.

DCISoft · Basic / Network Setup
IP ConfigurationStatic
IP Address192.168.10.10
Netmask255.255.255.0
Gateway0.0.0.0 · sin ruta externa
Esquema didáctico de campos · no es una captura del programa.

Si el firmware no acepta el valor de gateway sin ruta, revisa su manual con el docente; no atribuyas a una IP libre la función de router.

Escribe el cambio y vuelve a conectar

Confirma con OK / Apply y realiza la escritura al equipo que solicite la versión. Guardar un archivo de DCISoft en el PC no demuestra que se hayan escrito los parámetros en el PLC.

Al cambiar de subred puedes perder la conexión: es esperable. Devuelve PC1 a 192.168.10.20/24, vuelve a buscar y verifica que el PLC muestre 192.168.10.10. Reinicia solo si la herramienta lo solicita y el docente lo autoriza para la maqueta.

Verifica red y dato

ping 192.168.10.10
# PowerShell, si el proyecto usa Modbus TCP:
Test-NetConnection 192.168.10.10 -Port 502

Después lee un registro conocido desde KEPServerEX. Puerto accesible y ping no garantizan que la dirección Modbus ni el tipo de dato sean correctos.

Si DCISoft no encuentra el SE

  • Comprueba LED de enlace, alimentación y cable.
  • Revisa que elegiste el adaptador Ethernet correcto, sin puente con Wi-Fi.
  • Prueba un PLC a la vez; varios pueden conservar la misma IP inicial.
  • Confirma reglas del firewall para la herramienta; no lo desactives globalmente.
  • No restablezcas el PLC de fábrica para descubrir su IP.

DCISoft configura parámetros Ethernet. El programa lógico se trabaja en ISPSoft; son tareas distintas.
