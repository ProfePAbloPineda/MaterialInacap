Configura el equipo paso a paso

Distingue dirección local y destino

La HMI usa 192.168.10.40. El PLC que lee usa 192.168.10.10. No deben compartir dirección.

Asigna la IP propia del panel

En una DOP-B compatible, entra al menú del sistema mediante su botón posterior System Menu, manteniéndolo unos 3 segundos. Sigue System Settings → Network → LAN1 y desactiva DHCP.

Aplica y verifica en el propio panel. En otros modelos puede variar el acceso al menú; no uses una ruta DOP-100 como si fuera idéntica a DOP-B.

Configura el dispositivo que leerá la HMI

Abre tu proyecto en DOPSoft y entra a Options → Communication Setting (Opciones → Configuración de comunicación). En la sección Ethernet, distingue LocalHost —la propia HMI— del enlace al controlador remoto.

LocalHost debe reflejar 192.168.10.40/24. En el enlace Ethernet del PLC, selecciona el controlador Delta compatible y su IP 192.168.10.10. Puerto, estación y direcciones se toman del proyecto y del driver, no de la IP de PC1.

Selecciona Ethernet para transferir

DOPSoft → Options → Environment → Upload/Download → Ethernet

En DOPSoft 2.x compatible con DOP-B, el medio de transferencia se elige en el entorno de trabajo. Compila e inicia la descarga del PC hacia la HMI; indica 192.168.10.40, busca/actualiza y selecciona el panel. Confirma modelo antes de sobrescribir su proyecto.

Comprueba dos pantallas

Verifica en runtime una pantalla de proceso —nivel y estado— y otra de diagnóstico —voltaje y lectura cruda—. Cambia la fuente gradualmente y compara con Infilink.

Si el panel recibe el proyecto pero no muestra datos, revisa el enlace al PLC y las direcciones de los objetos. Transferencia correcta no equivale a comunicación de proceso correcta.
