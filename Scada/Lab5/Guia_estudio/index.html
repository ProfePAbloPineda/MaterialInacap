Propósito de la experiencia

Al finalizar podrás seleccionar un evento de Infilink, construir scripts sencillos y ejecutar una utilidad Python mediante un botón y un archivo por lotes de Windows. El foco está en el enlace y su diagnóstico; la utilidad externa puede cambiar sin reconstruir toda la pantalla.

Esta guía es de estudio y práctica. Las preguntas se conversan y comprueban durante la clase; el formulario de informe se realizará en una etapa posterior.

Conocimientos y recursos

  • Crear un proyecto, pantallas, objetos y tags en Infilink. Trabaja en una copia de tu proyecto.
  • PC Windows con Infilink-HMI y Python 3. Los ejemplos básicos no requieren PLC, KEPServerEX ni conexión OPC.
  • Editor de texto o Thonny. Acceso de escritura a una carpeta local de trabajo.
Referencia y versión. La sintaxis se contrastó con el manual público de KEP (edición 2004, capítulo de scripting) y sus recursos oficiales. Infilink 6 utiliza una interfaz con cinta de opciones; por eso algunos accesos cambian de ubicación. Usa Verify y la ayuda F1 de la versión instalada —por ejemplo 6.00.4-U— antes de ejecutar. Los ejemplos son desarrollos didácticos propios y no se han ejecutado dentro de tu instalación de Infilink.

01 / Estudiar y aplicar

Una secuencia de instrucciones, un evento que la inicia

Un script es una secuencia de instrucciones que se ejecuta cuando ocurre un evento. En una aplicación SCADA puede cambiar una variable interna, seleccionar una pantalla, elaborar un mensaje o iniciar una herramienta externa. No es un lenguaje universal: un script de Infilink, un archivo BAT y un programa Python tienen sintaxis y responsabilidades diferentes.

La pregunta que organiza el diseño

Antes de escribir código, define: ¿qué acción necesito, cuándo debe ocurrir y cómo comprobaré el resultado? “Abrir la ayuda al pulsar un botón” es preciso. “Ejecutar algo cuando el sistema funcione” no determina ni el momento ni la frecuencia.

CapaResponsabilidad en esta experienciaEvidencia que puedes observar
InfilinkRecibe la pulsación y solicita lanzar un proceso.Mensaje de diagnóstico y aparición de la consola.
Windows / cmd.exeInterpreta el archivo por lotes.Se muestran instrucciones y errores en la consola.
Archivo .batSelecciona Python, ubica el archivo .py y lo ejecuta.Ruta del intérprete y código de salida.
PythonRealiza la tarea: crear y abrir una nota.Aparece un archivo nuevo con fecha y hora.

Explora la cadena

Pulsa cada etapa para estudiar su función. Esta representación no ejecuta programas de Windows desde el navegador.

El operador realiza una pulsación. La acción se asigna a un evento de una sola ejecución por pulsación.
El lugar de ejecución es el PC de runtime. Si Infilink corre en PC2 y lee por OPC a PC1, Run(...) solicita iniciar el programa en PC2. No ejecuta automáticamente un archivo en PC1, en el PLC o en la HMI física. Los archivos y Python deben estar disponibles donde se ejecuta el runtime.

Un proceso externo no reemplaza los enclavamientos, la parada ni el control del PLC. En esta práctica solo se realizan tareas auxiliares: archivos, ayuda o visualización.

02 / Estudiar y aplicar

Pequeño repertorio de scripts útiles

Usa estos ejemplos como piezas de aprendizaje. Crea primero un grupo de tags de memoria llamado memDemo; así podrás practicar sin escribir sobre variables reales del PLC. Inserta referencias mediante el selector de tags del editor para respetar el nombre completo de tu proyecto.

Tag propuestoTipoValor inicial sugerido
memDemo\HabilitadoDiscrete / Boolean0
memDemo\ContadorLong / entero0
memDemo\NivelReal50
memDemo\ConsignaReal40
memDemo\MensajeStringVacío

2.1 Leer una instrucción sin confundir lenguajes

Infilink
# Comentario: identifica el objetivo de este boton.
memDemo\Consigna = 45;
memDemo\Mensaje = "Consigna de demostracion ajustada";

El comentario explica la intención; la primera asignación modifica un valor numérico y la segunda un texto. Cierra las instrucciones con ;. Copia comillas rectas, no las comillas tipográficas de un procesador de texto. Crear un nombre en el código no sustituye crear el tag en la base del proyecto.

2.2 Activar, desactivar e invertir un estado

Infilink
# Boton Activar:
memDemo\Habilitado = ON;

# En OTRO boton, Desactivar:
memDemo\Habilitado = OFF;

Para invertir el estado usa un tercer botón:

Infilink
Toggle memDemo\Habilitado;

Asocia un indicador visual al tag. Prueba una acción cada vez: si pegas Activar y Desactivar en el mismo evento, terminarás viendo el resultado de la última instrucción. Un indicador de memoria es una buena comprobación inicial antes de conectar acciones externas.

2.3 Contar acciones y reiniciar una prueba

Infilink
# Boton Contar:
memDemo\Contador = memDemo\Contador + 1;
Infilink
# OTRO boton: Reiniciar contador.
memDemo\Contador = 0;

Si una sola pulsación aumenta muchas unidades, investiga el evento y su intervalo: el problema puede estar en la repetición, no en la suma. Un contador sin límite puede desbordarse; este ejemplo solo se usa para pruebas cortas.

2.4 Tomar una decisión con If

Infilink
If (memDemo\Nivel >= 80) Then
    memDemo\Mensaje = "Nivel alto en la demostracion";
Else
    memDemo\Mensaje = "Nivel bajo el umbral";
EndIf;

Modifica el nivel de memoria, pulsa el botón y compara el mensaje con la condición. La evaluación sucede cuando se ejecuta el script: cambiar el nivel no actualiza este mensaje por sí solo si el evento elegido es un botón. Este ejemplo no configura el sistema de alarmas de Infilink ni implementa una protección del proceso.

2.5 Navegar entre ventanas del proyecto

Infilink
Show "Ayuda";
Infilink
Hide "Ayuda";

Crea previamente una ventana llamada Ayuda. Prueba la apertura desde Principal y su cierre desde un botón de Ayuda. El nombre interno debe coincidir con el usado en el script; no basta con un título visual parecido.

2.6 Dejar un rastro para depurar

Infilink
PostMsg("Se pulso el boton de prueba");
_SysCmd.EventLog;

Usa mensajes distintos en cada etapa de una prueba para reconocer qué parte alcanzó la ejecución. Un mensaje “terminado” escrito antes de lanzar un programa induciría a error: registra exactamente lo que sabes, por ejemplo “se solicitó iniciar”.

2.7 Mostrar acceso de usuarios

Infilink
_SysCmd.LogIn;
Infilink
_SysCmd.LogOut;

Estos ejemplos se prueban en botones separados, con los usuarios del proyecto preparados por el docente. Mostrar un diálogo de acceso no reemplaza configurar niveles y permisos. Evita incluir contraseñas en scripts.

2.8 Iniciar una aplicación externa

Infilink
Run("C:\Windows\System32\notepad.exe");

Este es el ensayo mínimo del lanzamiento externo. La ruta corresponde a una instalación habitual de Windows; comprueba la de tu PC. Si el Bloc de notas abre desde el botón, habrás probado la solicitud de lanzamiento, todavía no el BAT ni Python.

Práctica breve: primero domina el evento

  1. Crea un indicador de estado, un contador y un mensaje usando los tags de memoria.
  2. Implementa tres botones: cambiar estado, contar y evaluar nivel.
  3. Realiza cinco pulsaciones separadas en Contar y compara el resultado.
  4. Agrega el botón de ayuda y el de diagnóstico.

¿Cuál de tus scripts requiere que se pulse el botón y cuál necesitaría otro evento para actualizarse automáticamente?

03 / Estudiar y aplicar

El evento decide cuándo y cuántas veces se ejecuta

La misma instrucción puede ser apropiada o problemática según dónde se coloque. Abrir una aplicación una vez es útil; abrirla varias veces por segundo puede llenar el escritorio de procesos. Por eso se decide el evento antes de añadir la acción externa.

Evento / contextoPatrón que interesa reconocerDecisión didáctica
On button downUna ejecución al presionar.Usarlo para el lanzamiento de esta experiencia.
On button upUna ejecución al soltar.Alternativa si se desea disparar al liberar; no usar ambos para la misma tarea.
While button pressedRepetición mientras se mantiene presionado.No usarlo para iniciar Python en esta práctica.
On data change, en un tagReacciona al cambio del dato.Analizar variaciones y evitar lanzar procesos por cada muestra.
On project open / eventos de ventanaSe asocian al ciclo de vida de la interfaz.Útiles para preparación; no suponer que OPC ya está disponible al iniciar.
While project running / eventos periódicosRepiten una operación.Reservar para tareas breves y controladas; no abrir aplicaciones repetidamente.

Una sola ejecución por pulsación no significa una sola instancia

Si el operador pulsa tres veces, puede lanzar tres procesos. El evento de una sola ejecución no conoce necesariamente si una utilidad anterior sigue abierta. Durante la práctica, pulsa una vez, observa y cierra la consola antes de repetir. Para una aplicación permanente se debe diseñar un mecanismo de ocupación y confirmación; no basta con activar un bit que nunca vuelve a cero.

Regla de diseño: un evento solicita; un resultado observable confirma. Si Python debe devolver información al SCADA, hace falta un canal de retorno explícito —archivo acordado, OPC, API u otro mecanismo—, que no se incorpora todavía en esta guía.

¿Qué ocurriría si el lanzamiento estuviera tanto en On button down como en On button up? ¿Y si se coloca en un evento periódico de 500 ms?

04 / Estudiar y aplicar

Etapa A: prepara y prueba el programa Python

Usaremos una utilidad que crea una nota única con fecha y hora dentro de salidas y solicita abrirla con la aplicación asociada a los archivos TXT de Windows. No lee datos OPC ni del PLC; esa integración se puede construir posteriormente.

A1. Prepara la carpeta

C:\SCADA_Python

Usa esta ruta corta y sin espacios para la primera prueba. Si el PC no permite crear carpetas en C:, acuerda otra carpeta local con el docente y cambia todas las referencias. No se necesita elevar el runtime a administrador para resolver una ruta mal escrita.

En el Explorador activa Ver → Extensiones de nombre de archivo (o la opción equivalente). Evita que el archivo termine llamándose utilidad_scada.py.txt.

A2. Identifica el Python que vas a usar

En la consola de Thonny, IDLE o el intérprete instalado ejecuta:

Python · consola
import sys
print(sys.executable)

Copia la ruta completa del intérprete. Elige python.exe, no un acceso directo al editor ni pythonw.exe, porque necesitamos ver la consola y los errores. La ruta puede contener espacios; en los comandos de Windows se encerrará entre comillas.

En Símbolo del sistema, cmd.exe, prueba la ruta obtenida:

Windows CMD · sustituye la ruta
"C:\RUTA_REAL\python.exe" --version

Este comando se escribe en CMD. Si estás en PowerShell, la invocación de una ruta entre comillas requiere & delante. Para evitar mezclar sintaxis, realiza los pasos de esta guía en CMD.

A3. Guarda el programa

Descarga el ejemplo o escríbelo como utilidad_scada.py, en UTF-8, dentro de la carpeta de trabajo:

Python · utilidad_scada.py
from pathlib import Path
from datetime import datetime
import os
import sys


def main():
    base = Path(__file__).resolve().parent
    carpeta = base / "salidas"
    carpeta.mkdir(exist_ok=True)
    momento = datetime.now()
    archivo = carpeta / f"nota_{momento:%Y%m%d_%H%M%S_%f}.txt"
    texto = (
        "ENLACE SCADA - WINDOWS - PYTHON\n"
        f"Fecha: {momento:%d-%m-%Y %H:%M:%S}\n"
        "Se ejecuto el programa Python de la experiencia.\n"
        "Esta nota no contiene datos leidos del PLC.\n"
    )
    archivo.write_text(texto, encoding="utf-8")
    print(f"Interprete: {sys.executable}")
    print(f"Archivo creado: {archivo}")
    os.startfile(str(archivo))  # Windows: abrir con la aplicacion asociada.
    print("Se solicito abrir el archivo en Windows.")


if __name__ == "__main__":
    main()

A4. Ejecuta Python sin Infilink

Windows CMD · sustituye la ruta del intérprete
"C:\RUTA_REAL\python.exe" "C:\SCADA_Python\utilidad_scada.py"
Parte del programaQué debes comprender
Path(__file__).resolve().parentUbica la carpeta donde está el .py, sin depender de la carpeta desde la que lo lanzaron.
salidas y nombre con fecha/horaAgrupa resultados y evita sobrescribir la nota de una ejecución anterior.

Un archivo creado y una ventana abierta son dos resultados distintos. Si el TXT existe pero no abre, investiga la asociación de archivos de Windows. Que la llamada para abrir vuelva sin error no prueba que el operador haya leído el documento.
05 / Estudiar y aplicar

Etapa B: un archivo .bat como intermediario

La extensión correcta es .bat: un archivo por lotes que interpreta el procesador de comandos de Windows. Su función será elegir el intérprete y ejecutar el .py. El BAT no se convierte en Python; organiza su lanzamiento.

B1. Guarda ambos archivos juntos

CarpetaContenido inicial
C:\SCADA_Pythonutilidad_scada.py e iniciar_python.bat
C:\SCADA_Python\salidasSe crea al ejecutar el programa.

B2. Crea el BAT y configura una sola ruta

En el siguiente archivo reemplaza C:\CAMBIAR\python.exe por el intérprete obtenido con sys.executable. Descarga o guarda el archivo como iniciar_python.bat; en el Bloc de notas elige “Todos los archivos” para evitar la extensión TXT.

Windows BAT · iniciar_python.bat
@echo off
setlocal
rem Reemplaza esta ruta por la obtenida con sys.executable.
set "PYTHON_EXE=C:\CAMBIAR\python.exe"

if not exist "%PYTHON_EXE%" (
    echo ERROR: revisa PYTHON_EXE dentro de este archivo .bat.
    pause
    exit /b 2
)

cd /d "%~dp0"
if not exist "%~dp0utilidad_scada.py" (
    echo ERROR: falta utilidad_scada.py junto al archivo .bat.
    pause
    exit /b 3
)

echo Iniciando el programa Python...
"%PYTHON_EXE%" -u "%~dp0utilidad_scada.py"
set "CODIGO=%ERRORLEVEL%"
echo Codigo de salida de Python: %CODIGO%
echo Revision terminada. Pulsa una tecla para cerrar esta consola.
pause
exit /b %CODIGO%
InstrucciónFunción dentro de este ejemplo
set "PYTHON_EXE=..."Define la ruta de Python; las comillas protegen el valor frente a espacios. No agregues comillas dentro del valor.
if not existDa un mensaje concreto si faltan el intérprete o el programa.
cd /d "%~dp0"Cambia unidad y carpeta al lugar donde está el BAT. %~dp0 se refiere a esa ubicación.
"%PYTHON_EXE%" -u ...Ejecuta Python de forma directa; -u facilita ver salida de consola sin búfer.
set "CODIGO=%ERRORLEVEL%"Conserva inmediatamente el código de salida del proceso Python antes de ejecutar otros comandos.
pauseMantiene visible la consola para revisar durante la práctica.
exit /b %CODIGO%Devuelve el código conservado al contexto que llamó al BAT.

B3. Prueba el BAT sin Infilink

  1. Haz doble clic en iniciar_python.bat.
  2. Debe aparecer la consola, una nota nueva y la solicitud de apertura del TXT.
  3. Comprueba la ruta del intérprete y el código que muestra la consola.
  4. En este programa sencillo, una terminación normal muestra 0; una excepción no controlada suele devolver un código distinto de cero.
  5. Presiona una tecla para cerrar la consola solo después de leer el resultado.

No uses start en esta versión del BAT: queremos que el comando de Python termine antes de consultar su código. La aplicación que abre el TXT puede permanecer abierta después de que Python finalice.

En una versión de uso diario se podría retirar pause y guardar un log, pero no lo hagas antes de depurar. Ocultar la consola no corrige un error: solo lo vuelve más difícil de observar.
06 / Estudiar y aplicar

Etapa C: conecta el botón de Infilink con el BAT

Llegamos al enlace completo. No cambies el programa Python ni el BAT si ya aprobaron sus pruebas independientes; ahora debes comprobar exclusivamente la solicitud desde Infilink.

C1. Verifica primero el lanzamiento más simple

  1. En modo diseño, crea un botón llamado btnBlocNotas con una etiqueta clara.
  2. Selecciona el objeto y abre Animations → Take Action desde su menú contextual o la cinta equivalente.
  3. Selecciona On button down. Deja sin acción de lanzamiento While button pressed y On button up.
  4. Escribe la instrucción siguiente, verifica su sintaxis y acepta.
Infilink
Run("C:\Windows\System32\notepad.exe");

Guarda el proyecto y pasa a Run Mode. Pulsa una vez; cierra el Bloc de notas al terminar. Esta prueba permite separar un problema del evento de uno del BAT.

C2. Crea el botón definitivo

  1. Crea btnUtilidadPython con texto “Crear nota con Python”.
  2. Repite Animations → Take Action → On button down.
  3. Agrega este script completo. No necesita tags auxiliares.
Infilink
# Pegar en Take Action / On button down.
If Run("C:\Windows\System32\cmd.exe /d /c C:\SCADA_Python\iniciar_python.bat") Then
    PostMsg("Se solicito iniciar la utilidad externa.");
Else
    PostMsg("No fue posible lanzar el interprete de comandos.");
EndIf;
FragmentoPor qué se utiliza
C:\Windows\System32\cmd.exeEjecutable de Windows que interpretará el BAT. Ajustar si Windows está instalado en otra ruta.
/dEvita ejecutar comandos AutoRun del procesador de comandos.
/cEjecuta el comando pedido y termina después de que el BAT concluya. El pause interno demora ese cierre hasta pulsar una tecla.
C:\SCADA_Python\iniciar_python.batArchivo por lotes a ejecutar. La ruta corta inicial evita comillas anidadas.
If Run(...) ThenPermite distinguir si se pudo lanzar el proceso solicitado, no si Python realizó toda su tarea.

C3. Comprueba el recorrido completo

  1. Usa Verify y corrige cualquier error de sintaxis antes de abrir runtime.
  2. En Run Mode, pulsa una vez y observa la consola.
  3. Identifica el mensaje en el Event Logger; si es necesario, abre el visor con el botón de diagnóstico.
  4. Verifica que la nota tenga una fecha nueva. Una nota antigua no demuestra una ejecución reciente.
  5. Comprueba el código de salida y cierra la consola con una tecla.
Interpretación precisa de Run. En este ejemplo, TRUE indica que se pudo lanzar cmd.exe con la solicitud indicada. Si falta el BAT, Python o una dependencia, esa falla puede ocurrir después. El script de Infilink no recibe automáticamente el código de salida de Python ni espera una confirmación funcional. Por eso el mensaje dice “se solicitó iniciar”.

C4. Si luego utilizas una carpeta con espacios

Primero consigue que funcione la ruta simple. Si cambias a C:\Mi Proyecto, aparecen tres capas de interpretación: la cadena de Infilink, la línea de CMD y el contenido del BAT. Esta variante ilustra las comillas anidadas:

Infilink
Run("C:\Windows\System32\cmd.exe /d /s /c \"\"C:\Mi Proyecto\iniciar_python.bat\"\"");

Dentro de la cadena de Infilink, \" representa una comilla literal. CMD recibe:

Windows CMD · línea interpretada
C:\Windows\System32\cmd.exe /d /s /c ""C:\Mi Proyecto\iniciar_python.bat""

No copies comillas extras alrededor de toda la instrucción ni cambies indiscriminadamente todas las barras. Valida la cadena con la ayuda de tu versión. El BAT ya protege con comillas la ruta del intérprete y del .py.

¿Y una cámara?

La estructura de lanzamiento sería la misma, pero la aplicación requeriría su propia configuración: dispositivo disponible, permisos de cámara, librería elegida y manejo del cierre. No se incluye como prueba base para no mezclar la validación del enlace con instalaciones y dependencias de video.

Lo que todavía no hace esta integración

Un mensaje dentro de Python no modifica un tag de Infilink. Para pasar valores del proceso o devolver un resultado se debe acordar un intercambio de datos y validar tipo, unidad, vigencia, permisos y fallas. Tampoco se debe formar un comando Windows concatenando texto arbitrario que un operador pueda editar. Aquí se utiliza una acción fija y una ruta conocida.

08 / Estudiar y aplicar

Práctica integradora: demuestra que comprendes el enlace

Un objetivo, tres verificaciones

Construye un pequeño panel de utilidades en una copia de tu proyecto. Incluye “Ayuda”, “Ver eventos” y “Crear nota con Python”. No agregues todavía lectura OPC ni control de actuadores a la utilidad externa.

  1. Verificación 1: ejecuta directamente el .py y explica la ubicación y contenido de la nota.
  2. Verificación 2: ejecuta el BAT y explica cómo selecciona Python y conserva su código de salida.
  3. Verificación 3: ejecuta desde el botón, identifica el evento y compara mensajes con el resultado real.

Una falla controlada que enseña

Con los procesos cerrados, renombra temporalmente utilidad_scada.py a utilidad_scada_prueba.py. Pulsa una vez el botón. Observa si se inició la consola y qué error muestra el BAT. Después restaura el nombre original y verifica la recuperación. No modifiques ni borres archivos del sistema.

¿Por qué puede aparecer “se solicitó iniciar” en Infilink y, al mismo tiempo, “falta utilidad_scada.py” en la consola? Identifica exactamente qué etapa tuvo éxito y cuál falló.

Preguntas para conversar y comprobar

  1. ¿Qué diferencia existe entre un tag de memoria y uno vinculado por OPC? ¿Por qué usamos memoria al comenzar?
  2. ¿Qué ejecuta Infilink, qué interpreta Windows y qué realiza Python?
