INACAPEjemplo 3 · Entrada digital

Ejemplo 3

El pulsador decide el estado del LED

Código Arduino● ● ●
const int boton = 2;
const int led = 8;
int estadoBoton = 0;

void setup() {
  pinMode(boton, INPUT);
  pinMode(led, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  estadoBoton = digitalRead(boton);
  Serial.println(estadoBoton);

  if (estadoBoton == HIGH) {
    digitalWrite(led, HIGH);
  }
  else {
    digitalWrite(led, LOW);
  }

  delay(50);
}

INACAPEjemplo 4 · Antirrebote

Ejemplo 4

Una pulsación debe producir una acción

Código Arduino● ● ●
const int boton = 2;
const int led = 8;
bool estadoLed = false;

void setup() {
  pinMode(boton, INPUT);
  pinMode(led, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  if (digitalRead(boton) == HIGH) {
    delay(30);  // Espera el rebote inicial

    if (digitalRead(boton) == HIGH) {
      estadoLed = !estadoLed;
      digitalWrite(led, estadoLed);
      Serial.println("Pulsación válida");

      while (digitalRead(boton) == HIGH) {
        // Esperar hasta soltar el botón
      }

      delay(30);  // Rebote al liberar
    }
  }
}

if anidado + while de espera12
INACAPEjemplo 4 · Estructuras anidadas

Lectura del algoritmo

Tres estructuras, tres tareas diferentes

Primer if

Detecta que comenzó una posible pulsación.

Pregunta: ¿hay una entrada activa?

Segundo if

Confirma que la entrada continúa activa después de 30 ms.

Pregunta: ¿fue una pulsación real?

Ciclo while

Evita contar otra vez mientras el mismo botón sigue presionado.

Pregunta: ¿ya fue liberado?

Precisión conceptual: el delay(30) ayuda a filtrar el rebote mecánico; el while espera la liberación y evita repetir la misma pulsación.
Alcance: esta solución es adecuada para la práctica inicial. Más adelante se puede reemplazar por una rutina sin bloqueos basada en millis().

INACAPActividad integradora

Aplicación

Pulsador + antirrebote + función

Programa integrador● ● ●
const int boton = 2;
const int rojo = 8;
const int amarillo = 9;
const int verde = 10;

void setup() {
  pinMode(boton, INPUT);
  pinMode(rojo, OUTPUT);
  pinMode(amarillo, OUTPUT);
  pinMode(verde, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  if (digitalRead(boton) == HIGH) {
    delay(30);

    if (digitalRead(boton) == HIGH) {
      Serial.println("Ejecutando secuencia");
      secuencia();

      while (digitalRead(boton) == HIGH) { }
      delay(30);
    }
  }
}

void secuencia() {
  luz(rojo); luz(amarillo); luz(verde);
}

void luz(int pin) {
  digitalWrite(pin, HIGH);
  delay(300);
  digitalWrite(pin, LOW);
}
