CÓDIGO DE PRUEBA

LM35 y monitor serial

const int sensor = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int adc = analogRead(sensor);
  float voltaje = adc * 5.0 / 1023.0;
  float temperatura = voltaje * 100.0;

  Serial.println(temperatura, 1);
  delay(1000);
}

¿Qué debe comprobar el estudiante?

1. Lectura ADC válida.

2. Conversión a voltaje.

3. Conversión a °C.

4. Cambio de temperatura observado en el monitor serial.

DIAGNÓSTICO I²C

Detectar la dirección de la pantalla

#include <Wire.h>

void setup() {
  Wire.begin();
  Serial.begin(9600);
}

void loop() {
  for (byte dir = 1; dir < 127; dir++) {
    Wire.beginTransmission(dir);
    if (Wire.endTransmission() == 0) {
      Serial.println(dir, HEX);
    }
  }
  delay(3000);
}

Secuencia de verificación

1. Revisar VCC/GND y SDA/SCL.

2. Ejecutar el escáner.

3. Anotar la dirección detectada.

4. Configurar esa dirección en la librería LCD.

5. Ajustar el potenciómetro de contraste.

La librería Wire.h implementa la comunicación I²C.

ENTRADAS DIGITALES

Dos botones: ajustar la consigna

INPUT_PULLUP

Sin pulsar: HIGH.

Pulsado (conectado a GND): LOW.

Evita que la entrada quede flotante.

D2
Aumentar SP
D3
Disminuir SP
const int botonMas = 2;
const int botonMenos = 3;

void setup() {
  pinMode(botonMas, INPUT_PULLUP);
  pinMode(botonMenos, INPUT_PULLUP);
}

void loop() {
  if (digitalRead(botonMas) == LOW) {
    // Detectar pulsacion
  }
}

Considerar rebote mecánico y detección por flanco: una pulsación, un ajuste.
