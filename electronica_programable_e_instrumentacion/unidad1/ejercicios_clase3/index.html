CONTINUIDAD DE LA CLASE 01

Ahora el programa debe responder al hardware

Propósito: construir, probar y corregir programas para Arduino en Tinkercad a partir de montajes físicos. En esta guía el circuito es el punto de partida; el código se desarrolla de manera progresiva y no se entrega como solución terminada.

En la clase anterior ya trabajaste con salidas digitales, Monitor Serial, pulsadores, decisiones, antirrebote y funciones. En esta sesión usarás esos recursos para construir soluciones nuevas y comenzarás a integrar señales físicas de distinto tipo.

Montar
Construye primero el circuito y revisa alimentación, GND, polaridad y resistencias.
Programar
Escribe solo el bloque necesario para probar la etapa actual.
Comprobar
Simula, observa el circuito y usa el Monitor Serial antes de continuar.

FORMA DE TRABAJO

Una etapa a la vez

En cada ejercicio trabajarás con cuatro acciones repetidas:

1 · Construcción física
Agregar componentes, cablear y revisar conexiones.
2 · Código mínimo
Escribir únicamente lo necesario para probar esa etapa.
3 · Simulación
Modificar físicamente la entrada y observar la salida.
4 · Evidencia
Registrar valores o comportamiento antes de integrar una nueva función.
No copies una solución completa. Las cajas oscuras contienen pistas de estructura. Los espacios de código son para que construyas tu propia implementación en Tinkercad.

EJERCICIO 3 · SISTEMA INTEGRADO

Objetivo: integrar pulsador, potenciómetro, LED y un segundo actuador. El Monitor Serial permitirá seleccionar el modo de operación, pero el comportamiento del sistema dependerá de las entradas físicas.

A. Ampliación del circuito

B. Modos de funcionamiento

Selección SerialModoComportamiento físico
1MonitoreoMostrar continuamente pulsador y potenciómetro. Las salidas permanecen detenidas.
2ManualEl pulsador controla una salida; el potenciómetro modifica un parámetro físico de la otra.
3AutomáticoArduino toma decisiones a partir de las entradas y ejecuta una respuesta programada.

C. Organiza el programa mediante funciones

Define una función para cada modo. loop() debe seleccionar qué función ejecutar según el modo actual.

void loop() { revisar si llegó una selección por Serial actualizar variable [modo] si modo es 1 → llamar función de monitoreo si modo es 2 → llamar función manual si modo es 3 → llamar función automática }
