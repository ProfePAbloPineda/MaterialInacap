Lenguaje común

Cómo nombrar posiciones y movimientos

Cilindro A

a0 retraído a1 extendido A+ avanzar A− retroceder

Para B se usan b0, b1, B+ y B−. Para C se usan c0, c1, C+ y C−.

Señales del PLC

  • X: entrada física, como pulsador o sensor.
  • Y: salida física conectada a una bobina.
  • M: memoria interna usada como etapa.
  • T: temporizador.

INACAPFundamentos de programación Ladder

Lectura de redes

El PLC evalúa condiciones de izquierda a derecha y de arriba hacia abajo

Contacto NO

Conduce cuando su variable vale 1.

Contacto NC

Conduce cuando su variable vale 0.

Bobina

Escribe el resultado lógico en una salida o memoria.

SET / RST

Enclava o borra una memoria aunque la condición deje de estar activa.

R1X0 START · /X1 STOP · a0SET M1
R2M1 · a1RST M1 / SET M2
R3M1 + M2Y0
Convención de esta guía: el punto “·” significa AND, el signo “+” significa OR y “/X1” representa una condición negada o contacto normalmente cerrado. La lógica es independiente de marca: adapta el relé de primer barrido y la base de tiempo a tu PLC.

INACAPMétodo de diseño

Regla principal

Una etapa responde tres preguntas

1. ¿Qué está ocurriendo?

Ejemplo: el cilindro A está avanzando. La memoria M1 identifica esa etapa.

2. ¿Qué salida debe activarse?

Mientras M1 esté activa, la salida correspondiente genera A+.

3. ¿Cuándo termina?

El sensor a1 confirma el final del avance y habilita la etapa siguiente.

Principio de exclusión: durante el ciclo debe existir una sola memoria de etapa activa. Si dos etapas quedan activas al mismo tiempo, pueden aparecer órdenes contradictorias.
Regla de transición: una misma condición de cambio debe activar la etapa siguiente y desactivar la etapa actual.
Estado + acción + condición de término07
INACAPMétodo de diseño

Antes de abrir el software

Diseña la secuencia en cinco pasos

1

Escribe el ciclo

Ejemplo: A+ A−.

2

Comprueba la posición inicial

El sensor a0 debe estar activo.

3

Crea una tabla de etapas

Una fila por movimiento o espera.

4

Programa las transiciones

Cada sensor o temporizador permite avanzar.

5

Asocia etapas con salidas

Las salidas no deciden la secuencia: obedecen a las memorias.

Consejo: no comiences programando bobinas. Primero termina la tabla de etapas; luego el Ladder se vuelve una traducción ordenada.

INACAPSeguridad funcional de la secuencia

Situaciones reales

STOP, RESET y emergencia no significan lo mismo

STOP de proceso

Detiene el ciclo de manera programada. Puede conservar el estado para continuar o exigir un reinicio.

RESET de secuencia

Borra las memorias de movimiento, activa reposo y verifica sensores antes de aceptar START.

Emergencia

Debe actuar mediante un sistema de seguridad adecuado, no solo mediante lógica Ladder estándar.

Importante: cortar bobinas no garantiza el mismo comportamiento en una válvula monoestable y en una biestable. La reacción neumática debe analizarse antes de definir el reset.
Detener no siempre significa retornar33
INACAPDiagnóstico de programas secuenciales

Errores frecuentes

Cuando la secuencia no avanza, revisa el estado antes de cambiar el código

Ninguna etapa activa: faltó inicializar la memoria de reposo o un reset borró todas las etapas.
Dos etapas activas: una transición hizo SET de la siguiente, pero no RST de la anterior.
Movimiento detenido: el sensor final no cambia o está asignado a otra entrada.
Bobinas opuestas activas: falta interbloqueo o existen etapas incompatibles.
Diagnóstico basado en evidencias34
INACAPComprobación del programa

Prueba sistemática

No basta con observar un ciclo correcto

Antes de START, solo está activa la etapa de reposo.
START no funciona si falta un sensor de posición inicial.
Cada etapa activa exactamente las salidas previstas.
Cada sensor produce una sola transición.
No existen dos órdenes opuestas sobre la misma válvula.
Un sensor que no llega detiene el avance de la secuencia.
STOP y RESET producen el comportamiento definido.
Después de energizar el PLC, el estado es conocido.
Método recomendado: monitorea primero memorias M, luego entradas X y finalmente salidas Y. Así separas un error de secuencia de un problema eléctrico o neumático.
